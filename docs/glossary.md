# Глоссарий проекта


| Термин                                    | Определение                                                                                                                                                                           |
|-------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Потребительский спрос       | Количество единиц товара, востребованное покупателями за определённый период                                                 |
| История продаж                     | Набор фактических сведений о продажах, упорядоченный по времени                                                                           |
| Продажа                                  | Факт реализации определённого количества товара за указанную дату или период                                                  |
| Временной ряд                       | Последовательность значений показателя, связанных с последовательными моментами или периодами времени |
| Прогноз                                  | Рассчитанная оценка будущего значения спроса                                                                                                             |
| Горизонт прогнозирования | Количество будущих периодов, для которых формируется прогноз                                                                                |
| Прогнозное значение           | Рассчитанное моделью значение спроса для конкретного будущего периода                                                              |
| Предобработка                      | Очистка и преобразование данных перед передачей модели                                                                                           |
| Обучающая выборка               | Часть данных, используемая для настройки параметров модели                                                                                    |
| Валидационная выборка       | Часть данных, используемая для выбора параметров и контроля обучения                                                                  |
| Тестовая выборка                 | Часть данных, используемая для итоговой оценки модели                                                                                              |
| Baseline                                        | Простая базовая модель, с которой сравнивается более сложное решение                                                                  |
| Нейросетевая модель           | Математическая модель, основанная на искусственных нейронных сетях                                                                    |
| LSTM                                            | Разновидность рекуррентной нейронной сети, предназначенная для обработки последовательностей                 |
| Метрика качества                 | Численный показатель величины ошибки модели                                                                                                               |
| MAE                                             | Средняя абсолютная ошибка прогноза                                                                                                                                |
| RMSE                                            | Корень из средней квадратичной ошибки                                                                                                                           |
| MAPE                                            | Средняя абсолютная процентная ошибка                                                                                                                            |
| ML-сервис                                 | Изолированный программный компонент, выполняющий предобработку и прогнозирование                                        |
| Серверный компонент           | Компонент, содержащий бизнес-логику и координирующий работу системы                                                                   |
| Клиентский компонент         | Пользовательский интерфейс программной системы                                                                                                        |
| SKU                                             | Уникальное обозначение товарной позиции                                                                                                                      |
| MVP                                             | Минимальная версия продукта, содержащая основные функции                                                                                       |
| AS-IS                                           | Описание бизнес-процесса в текущем состоянии                                                                                                              |
| TO-BE                                           | Описание целевого бизнес-процесса после автоматизации                                                                                            |
