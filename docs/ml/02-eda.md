# Exploratory Data Analysis

## 1. Цель исследования

Целью разведочного анализа данных является исследование структуры временных рядов спроса перед построением и сравнением моделей прогнозирования.

На этапе EDA необходимо определить:

- объём и временной диапазон данных;
- количество анализируемых товаров;
- распределение целевой переменной `quantity`;
- наличие пропущенных и нулевых значений;
- длину временных рядов;
- наличие временной зависимости;
- наличие признаков сезонности;
- пригодность данных для дальнейшего моделирования.

На данном этапе модели прогнозирования не обучаются.

## 2. Используемый датасет

Для разработки ML-конвейера используется воспроизводимый синтетический набор данных.

Датасет не является набором реальных рыночных наблюдений и используется для:

- разработки методов анализа;
- проверки алгоритмов прогнозирования;
- сравнения baseline-модели и нейросетевой модели;
- тестирования полного ML-конвейера.

Результаты анализа синтетического набора не интерпретируются как характеристики реального рынка потребительского спроса.

Она характеризует количество единиц товара, реализованных за один календарный день.

Диапазон от 17 до 135 единиц показывает заметную изменчивость ежедневного спроса, достаточную для исследования задачи прогнозирования.

## 7. Временная зависимость

Для исследования зависимости текущего спроса от предыдущих значений рассчитана автокорреляция с лагами:

- 1 день;
- 7 дней;
- 14 дней;
- 30 дней;
- 365 дней.

Для всех восьми товаров наблюдается выраженная положительная автокорреляция.

### Лаг 1 день

Значения находятся приблизительно в диапазоне:

`0.75–0.79`

Это означает, что спрос соседних календарных дней существенно связан.

Следовательно, предыдущие наблюдения содержат информацию, полезную для прогнозирования будущего спроса.

### Лаг 7 дней

Автокорреляция составляет приблизительно:

`0.83–0.89`

Это наиболее выраженная зависимость среди рассмотренных коротких лагов.

Высокое значение на лаге 7 дней свидетельствует о наличии недельной повторяемости временных рядов.

### Лаг 14 дней

Получены значения приблизительно:

`0.81–0.87`

Высокая корреляция сохраняется и при смещении на две недели, что дополнительно подтверждает устойчивость недельной структуры.

### Лаг 30 дней

Значения находятся приблизительно в диапазоне:

`0.47–0.52`

Связь между наблюдениями сохраняется, однако значительно слабее, чем для лагов 7 и 14 дней.

Таким образом, месячный лаг обладает меньшей информативностью по сравнению с недельной периодичностью.

### Лаг 365 дней

Автокорреляция находится приблизительно в диапазоне:

`0.73–0.80`

Это указывает на выраженную повторяемость значений через один год.

В синтетическом датасете данный эффект является ожидаемым, поскольку годовая компонента была предусмотрена при генерации экспериментальных данных.

## 8. Сезонность

На основании полученных коэффициентов автокорреляции можно выделить две основные периодические структуры:

1. недельная;
2. годовая.

Наиболее сильная зависимость наблюдается для недельных лагов.

Наличие высокой корреляции на лаге 365 дней дополнительно показывает долгосрочную сезонную структуру временного ряда.

При этом данные результаты относятся к синтетическому набору и не должны рассматриваться как доказательство аналогичной сезонности реального потребительского спроса.

## 9. Пригодность данных для прогнозирования

Датасет пригоден для последующих экспериментальных этапов проекта по следующим причинам:

- каждый товар имеет 974 последовательных ежедневных наблюдения;
- временные ряды не содержат разрывов;
- отсутствуют дубликаты;
- отсутствуют отрицательные значения;
- отсутствуют пропущенные значения;
- присутствует изменчивость целевой переменной;
- присутствует временная зависимость;
- присутствуют краткосрочные и долгосрочные периодические компоненты;
- объём данных позволяет сформировать отдельные train, validation и test интервалы.

Особенно важным результатом является наличие выраженной зависимости от предыдущих значений временного ряда.

Это обосновывает применение методов прогнозирования, использующих историческую последовательность наблюдений.

## 10. Ограничения анализа

Основное ограничение текущего исследования заключается в происхождении данных.

Используемый набор является синтетическим.

В частности, при его генерации были заложены:

- базовый уровень спроса;
- недельная периодичность;
- годовая сезонная компонента;
- постепенный тренд;
- случайный шум.

Поэтому наличие обнаруженной недельной и годовой зависимости является ожидаемым свойством сгенерированных данных.

Основная задача такого набора — обеспечить воспроизводимую экспериментальную среду для разработки и сравнения методов прогнозирования.

Если в дальнейшем будет получен достаточный объём реальных исторических продаж, аналогичный EDA необходимо выполнить повторно уже для реальных данных.

## 11. Вывод

В ходе разведочного анализа исследован подготовленный набор данных для прогнозирования потребительского спроса.

Датасет содержит 7792 ежедневных наблюдения по восьми товарам. Для каждого товара имеется 974 последовательных наблюдения. Пропущенные, отрицательные и нулевые значения отсутствуют.

Среднее значение ежедневного спроса составляет 68.59 единицы, медианное — 68 единиц, а стандартное отклонение — 25.13.

Анализ автокорреляции показал выраженную зависимость значений спроса от предыдущих наблюдений. Наиболее высокая корреляция наблюдается для лагов 7 и 14 дней, что указывает на устойчивую недельную структуру. Высокая автокорреляция также наблюдается на лаге 365 дней.

Полученный набор данных является пригодным для дальнейшего экспериментального сравнения методов прогнозирования.

На следующем этапе в качестве базового метода будет разработана модель Moving Average. Она будет использоваться как baseline, относительно которого впоследствии будет оцениваться эффективность нейросетевой модели LSTM.
