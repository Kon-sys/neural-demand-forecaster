# Постановка задачи

## 1. Общая постановка задачи

Необходимо разработать программное средство прогнозирования потребительского спроса на основе нейросетевых методов.

Программное средство должно обеспечивать обработку исторических данных о продажах, подготовку данных для анализа, построение прогноза спроса на заданный временной период и представление результатов пользователю в удобной форме.

Основной задачей системы является повышение точности оценки будущего потребительского спроса и снижение зависимости процесса планирования от субъективных экспертных оценок.

## 2. Входные данные

В качестве входных данных программное средство должно использовать историческую информацию о продажах товаров.

Входные данные могут включать:

- идентификатор товара;
- категорию товара;
- дату продажи;
- количество проданных единиц товара;
- цену товара;
- сведения о скидках и акциях;
- временные характеристики;
- дополнительные признаки, влияющие на изменение спроса.

Перед передачей данных в модель прогнозирования должна выполняться предварительная обработка, включающая проверку корректности данных, обработку пропущенных значений, преобразование признаков и формирование временных последовательностей.

## 3. Основные функции программного средства

Разрабатываемое программное средство должно обеспечивать выполнение следующих функций:

1. Загрузка исторических данных о продажах.
2. Проверка и предварительная обработка исходных данных.
3. Формирование набора признаков, используемых для прогнозирования.
4. Обучение нейросетевой модели на исторических данных.
5. Построение прогноза потребительского спроса.
6. Сохранение полученных прогнозных значений.
7. Сравнение прогнозируемых и фактических значений.
8. Расчёт метрик качества модели прогнозирования.
9. Представление результатов прогнозирования пользователю.
10. Просмотр истории ранее сформированных прогнозов.

## 4. Выходные данные

Результатом работы программного средства должен являться прогноз потребительского спроса для выбранных товаров на заданный временной период.

Для каждого прогноза должны быть доступны:

- идентификатор товара;
- период прогнозирования;
- прогнозируемое значение спроса;
- фактическое значение при его наличии;
- дата формирования прогноза;
- версия модели прогнозирования;
- показатели качества модели.

Результаты должны быть представлены в форме, позволяющей пользователю анализировать изменение спроса во времени и сравнивать фактические и прогнозируемые показатели.

## 5. Требования к модели прогнозирования

Модель должна строить прогноз на основании исторических данных о продажах и учитывать временную зависимость значений спроса.

Для оценки качества прогнозирования должны использоваться количественные метрики ошибки.

В качестве основных метрик предполагается использовать:

- MAE — среднюю абсолютную ошибку;
- RMSE — среднеквадратичную ошибку;
- MAPE — среднюю абсолютную процентную ошибку.

Выбор окончательной архитектуры нейросетевой модели должен осуществляться на основании экспериментального сравнения рассматриваемых подходов и результатов их работы на подготовленном наборе данных.

## 6. Ограничения задачи

При разработке программного средства необходимо учитывать следующие ограничения:

- качество прогноза зависит от объёма и качества исторических данных;
- отсутствие достаточной истории продаж может снижать точность прогнозирования;
- резкие изменения спроса, вызванные внешними факторами, могут быть недостаточно представлены в исторических данных;
- обучение нейросетевой модели требует дополнительных вычислительных ресурсов;
- программное средство не должно самостоятельно принимать управленческие решения на основании сформированного прогноза.

Прогноз должен использоваться как информационная поддержка процесса анализа и планирования спроса.

## 7. Ожидаемый результат

В результате выполнения проекта должно быть разработано программное средство, позволяющее на основании исторических данных автоматически формировать прогноз потребительского спроса.

Система должна объединять процессы подготовки данных, применения нейросетевой модели, хранения результатов прогнозирования и визуального анализа полученных значений.

Разработанное решение должно обеспечивать возможность дальнейшего расширения набора используемых признаков, совершенствования модели прогнозирования и интеграции дополнительных методов анализа данных.
