# Анализ научно-технических подходов и методов решения

## 1. Цель анализа

Целью анализа является исследование методов и подходов, применяемых для прогнозирования временных рядов и потребительского спроса, а также выбор методов, наиболее подходящих для реализации интеллектуального компонента программного средства Demand Forecast.

При выборе подхода необходимо учитывать следующие особенности задачи:

- наличие исторических данных о продажах;
- последовательный характер данных во времени;
- возможное наличие тренда и сезонных закономерностей;
- необходимость прогнозирования значений на будущий период;
- необходимость количественной оценки качества прогнозирования;
- необходимость сравнения интеллектуальной модели с более простым базовым методом;
- возможность реализации интеллектуального компонента в виде отдельного программного сервиса;
- возможность дальнейшего расширения модели дополнительными признаками.

## 2. Особенности задачи прогнозирования спроса

Потребительский спрос может быть представлен в виде временного ряда, содержащего последовательность значений продаж, упорядоченных по времени.

В общем виде временной ряд может быть представлен следующим образом:

```text
Y = {y₁, y₂, y₃, ..., yₜ}
```

где:

- `yₜ` — значение спроса в момент времени `t`;
- `t` — временной индекс.

Задача прогнозирования заключается в построении модели, которая на основании предыдущих значений временного ряда позволяет определить будущие значения:

```text
ŷₜ₊₁, ŷₜ₊₂, ..., ŷₜ₊ₕ
```

где:

- `ŷ` — прогнозируемое значение;
- `h` — горизонт прогнозирования.

При анализе временного ряда необходимо учитывать несколько возможных компонентов:

- общий уровень ряда;
- тренд;
- сезонность;
- циклические изменения;
- случайные колебания;
- аномальные значения.

Качество прогноза зависит не только от выбранного алгоритма, но и от полноты, качества и продолжительности исходного временного ряда.

## 3. Основные подходы к прогнозированию временных рядов

Для решения задачи прогнозирования могут применяться следующие группы методов:

1. Простые статистические методы.
2. Классические модели временных рядов.
3. Методы машинного обучения.
4. Нейросетевые методы.

Каждая группа методов имеет собственные преимущества, ограничения и область применения.

При разработке Demand Forecast необходимо рассмотреть несколько подходов, поскольку использование более сложной интеллектуальной модели должно быть обосновано результатами сравнения с более простыми методами.

## 4. Простые статистические методы

### 4.1 Скользящее среднее

Одним из наиболее простых методов прогнозирования является скользящее среднее.

Прогнозное значение определяется как среднее значение нескольких последних наблюдений:

```text
ŷₜ₊₁ = (yₜ + yₜ₋₁ + ... + yₜ₋ₙ₊₁) / n
```

где:

- `n` — размер окна;
- `y` — фактические значения временного ряда.

Например, если используется окно из семи предыдущих наблюдений, прогноз следующего значения определяется как среднее значение спроса за последние семь временных интервалов.

Преимущества метода:

- простота реализации;
- высокая скорость вычислений;
- низкие требования к вычислительным ресурсам;
- понятность результата;
- отсутствие необходимости обучения сложной модели;
- возможность использования как базового метода для сравнительной оценки.

Недостатки:

- слабая способность моделировать сложные нелинейные зависимости;
- ограниченная способность учитывать тренд;
- ограниченная способность учитывать сезонность;
- снижение качества при резких изменениях спроса;
- зависимость результата от выбранного размера окна.

В проекте Demand Forecast скользящее среднее целесообразно использовать в качестве базовой модели, с которой будет сравниваться результат нейросетевого прогнозирования.

### 4.2 Экспоненциальное сглаживание

Методы экспоненциального сглаживания используют взвешенную комбинацию предыдущих значений временного ряда, при этом более новые наблюдения получают больший вес.

Простейшая модель может быть представлена следующим образом:

```text
Sₜ = αyₜ + (1 - α)Sₜ₋₁
```

где:

- `Sₜ` — сглаженное значение;
- `α` — коэффициент сглаживания;
- `yₜ` — наблюдаемое значение.

Методы экспоненциального сглаживания хорошо подходят для относительно стабильных временных рядов.

Существуют расширенные варианты данного подхода, позволяющие учитывать тренд и сезонность.

Преимущества:

- относительная простота;
- небольшие вычислительные затраты;
- возможность учитывать более свежие наблюдения с большим весом;
- возможность расширения для анализа тренда и сезонности;
- хорошая интерпретируемость.

Недостатки:

- ограниченная способность моделировать сложные нелинейные зависимости;
- необходимость выбора параметров сглаживания;
- снижение эффективности при сложном поведении временного ряда.

## 5. Классические модели временных рядов

### 5.1 ARIMA

ARIMA представляет собой один из классических статистических подходов к прогнозированию временных рядов.

Название ARIMA образовано от компонентов:

- `AR` — авторегрессионная составляющая;
- `I` — интегрирование;
- `MA` — скользящее среднее ошибок.

Модель обычно обозначается следующим образом:

```text
ARIMA(p, d, q)
```

где:

- `p` — порядок авторегрессии;
- `d` — порядок дифференцирования;
- `q` — порядок скользящего среднего.

Преимущества ARIMA:

- развитая теоретическая база;
- хорошая интерпретируемость;
- эффективность при работе с линейными временными зависимостями;
- возможность получения качественных результатов для подходящих временных рядов.

Недостатки:

- необходимость анализа стационарности ряда;
- необходимость подбора параметров;
- ограниченные возможности моделирования нелинейных процессов;
- необходимость дополнительной настройки при работе с сезонностью;
- увеличение сложности при работе с большим количеством различных временных рядов.

### 5.2 SARIMA

SARIMA является расширением ARIMA и позволяет учитывать сезонную составляющую временного ряда.

Такой метод целесообразен, если спрос имеет выраженную периодичность, например:

- дневную;
- недельную;
- месячную;
- квартальную;
- годовую.

Преимуществом SARIMA является возможность явно учитывать сезонные закономерности.

Недостатками являются:

- необходимость предварительного анализа временного ряда;
- необходимость настройки большого количества параметров;
- ограниченная способность учитывать сложные нелинейные зависимости.

ARIMA и SARIMA представляют интерес как классические методы прогнозирования и могут использоваться при сравнительном исследовании, однако не являются основной интеллектуальной моделью Demand Forecast.

## 6. Методы машинного обучения

Для прогнозирования спроса могут применяться классические алгоритмы машинного обучения.

В таком случае временной ряд предварительно преобразуется в набор признаков, подходящих для решения задачи регрессии.

В качестве признаков могут использоваться:

- предыдущие значения продаж;
- скользящие средние;
- минимальные и максимальные значения за определённый период;
- день недели;
- номер недели;
- месяц;
- сезон;
- праздничные периоды;
- цена товара;
- скидки;
- рекламные мероприятия;
- другие внешние факторы.

Для этого могут применяться следующие алгоритмы:

- Linear Regression;
- Decision Tree;
- Random Forest;
- Gradient Boosting;
- XGBoost.

### 6.1 Преимущества методов машинного обучения

К преимуществам относятся:

- способность моделировать нелинейные зависимости;
- возможность учитывать большое количество признаков;
- возможность добавления внешних факторов;
- высокая эффективность при работе со структурированными данными;
- возможность оценки важности отдельных признаков для некоторых алгоритмов.

### 6.2 Ограничения методов машинного обучения

Основным ограничением является необходимость предварительного формирования признаков временного ряда.

Например, для использования предыдущих значений продаж необходимо создавать лаговые признаки:

```text
lag_1
lag_2
lag_3
lag_7
lag_14
...
```

Таким образом, классический алгоритм машинного обучения не воспринимает временную последовательность напрямую.

Разработчик должен самостоятельно определить:

- какие предыдущие значения учитывать;
- какие временные признаки создавать;
- какие дополнительные факторы использовать;
- какое окно наблюдений применять.

Поэтому для задачи, непосредственно связанной с анализом последовательных данных, дополнительно необходимо рассмотреть нейросетевые архитектуры.

## 7. Нейросетевые методы

Нейросетевые методы позволяют моделировать сложные нелинейные зависимости.

Для анализа временных последовательностей могут применяться:

- RNN;
- LSTM;
- GRU;
- архитектуры на основе механизма Attention и Transformer.

В отличие от классических алгоритмов машинного обучения, рекуррентные нейронные сети специально предназначены для обработки последовательностей.

## 8. Рекуррентные нейронные сети

### 8.1 RNN

Recurrent Neural Network представляет собой тип нейронной сети, предназначенный для обработки последовательных данных.

В отличие от обычной полносвязной нейронной сети, RNN использует информацию о предыдущем состоянии при обработке очередного элемента последовательности.

Обобщённо этот процесс можно представить следующим образом:

```text
hₜ = f(xₜ, hₜ₋₁)
```

где:

- `xₜ` — входное значение на текущем временном шаге;
- `hₜ₋₁` — скрытое состояние предыдущего шага;
- `hₜ` — новое скрытое состояние.

Таким образом, результат обработки текущего значения зависит не только от самого значения, но и от ранее обработанной информации.

Преимуществом RNN является возможность учитывать последовательный характер данных.

Основным недостатком классической RNN является проблема затухающих и взрывающихся градиентов.

При обработке длинных последовательностей модель может терять информацию о событиях, находящихся далеко от текущего временного шага.

Для решения данной проблемы были разработаны более совершенные рекуррентные архитектуры.

## 9. LSTM

Long Short-Term Memory является разновидностью рекуррентной нейронной сети, разработанной для более эффективной обработки долгосрочных зависимостей.

LSTM использует состояние памяти и специальные управляющие механизмы, которые определяют, какая информация должна:

- сохраняться;
- обновляться;
- удаляться;
- использоваться при формировании результата.

В архитектуре LSTM используются:

- входной вентиль;
- вентиль забывания;
- выходной вентиль;
- состояние ячейки памяти.

Благодаря этому модель способна сохранять значимую информацию на протяжении относительно длинной последовательности.

### 9.1 Преимущества LSTM

К преимуществам относятся:

- способность анализировать последовательные данные;
- возможность учитывать долгосрочные зависимости;
- возможность моделировать нелинейные закономерности;
- применимость к задачам прогнозирования временных рядов;
- возможность использования нескольких входных признаков;
- возможность автоматического выявления определённых закономерностей временной последовательности;
- отсутствие необходимости заранее определять строгую математическую структуру исследуемого процесса.

### 9.2 Недостатки LSTM

К ограничениям относятся:

- более высокая вычислительная сложность по сравнению с простыми статистическими методами;
- необходимость обучения модели;
- зависимость результата от объёма обучающих данных;
- зависимость результата от качества исходных данных;
- необходимость настройки гиперпараметров;
- более сложная интерпретация результата;
- риск переобучения при недостаточном количестве данных.

Несмотря на перечисленные ограничения, LSTM подходит для задачи Demand Forecast, поскольку курсовой проект предполагает исследование и применение нейросетевой модели для прогнозирования потребительского спроса.

## 10. GRU

Gated Recurrent Unit представляет собой другую разновидность рекуррентной нейронной сети.

GRU использует более простую архитектуру по сравнению с LSTM и содержит меньше управляющих механизмов.

К преимуществам GRU относятся:

- меньшее количество параметров;
- потенциально более быстрое обучение;
- способность учитывать долгосрочные зависимости;
- меньшая вычислительная сложность по сравнению с LSTM в ряде задач.

При этом LSTM использует отдельное состояние ячейки памяти и предоставляет более детализированный механизм управления информацией.

В рамках Demand Forecast основным нейросетевым методом предлагается использовать LSTM.

GRU может рассматриваться как дополнительный вариант для дальнейшего исследования или последующего расширения системы.

## 11. Transformer-подходы

Современные архитектуры на основе механизма Attention также могут применяться для прогнозирования временных рядов.

Основным отличием таких моделей является возможность анализировать взаимосвязи между различными элементами последовательности без использования классической рекуррентной обработки.

К преимуществам Transformer-подходов относятся:

- эффективная работа с длинными зависимостями;
- возможность анализа сложных взаимосвязей;
- высокая гибкость архитектуры;
- возможность применения к многомерным временным рядам.

Однако такие модели обычно требуют:

- большего объёма данных;
- более сложной архитектуры;
- дополнительных вычислительных ресурсов;
- более сложной настройки;
- более трудоёмкой реализации.

Для текущего объёма курсового проекта применение Transformer-архитектуры может привести к неоправданному усложнению интеллектуального компонента.

Поэтому данный подход рассматривается как перспективное направление развития, но не выбирается в качестве основной модели первой версии Demand Forecast.

## 12. Подготовка данных для нейросетевой модели

Перед использованием LSTM исходные данные должны пройти предварительную обработку.

Основные этапы подготовки включают:

1. Проверку структуры входных данных.
2. Проверку типов данных.
3. Сортировку записей по времени.
4. Обработку пропущенных значений.
5. Анализ аномальных значений.
6. Формирование временного ряда.
7. Масштабирование данных.
8. Формирование входных последовательностей.
9. Разделение данных на обучающую, валидационную и тестовую выборки.

### 12.1 Формирование последовательностей

Для обучения LSTM исходный временной ряд преобразуется в набор последовательностей фиксированной длины.

Например:

```text
[y₁, y₂, y₃, y₄, y₅] → y₆
[y₂, y₃, y₄, y₅, y₆] → y₇
[y₃, y₄, y₅, y₆, y₇] → y₈
```

Левая часть представляет входные данные модели, а значение после стрелки является целевым значением.

Таким образом, нейронная сеть получает определённое количество предыдущих наблюдений и обучается прогнозировать последующее значение.

Количество предыдущих значений, передаваемых модели, называется длиной входного окна и является одним из гиперпараметров.

## 13. Масштабирование данных

Для нейросетевых моделей целесообразно выполнять масштабирование исходных значений.

Например, значения продаж могут быть приведены к диапазону:

```text
[0; 1]
```

Масштабирование позволяет избежать ситуации, при которой большие абсолютные значения оказывают чрезмерное влияние на процесс обучения.

После получения прогноза выполняется обратное преобразование, позволяющее вернуть прогнозные значения к исходному масштабу.

Важно, чтобы параметры масштабирования определялись на основании обучающей выборки.

Использование информации тестовой выборки при настройке предварительной обработки может привести к утечке данных и некорректной оценке качества модели.

## 14. Разделение данных

Для корректной оценки качества модели временной ряд нельзя случайным образом перемешивать перед разделением.

При случайном перемешивании будущие наблюдения могут попасть в обучающую выборку, что нарушает реальный сценарий прогнозирования.

Поэтому разделение должно выполняться с сохранением временного порядка:

```text
Временной ряд
      ↓
┌────────────────┬────────────────┬────────────────┐
│ Train          │ Validation     │ Test           │
│ ранние данные  │ следующие      │ последние      │
└────────────────┴────────────────┴────────────────┘
```

Обучающая выборка используется для изменения параметров модели в процессе обучения.

Валидационная выборка используется для:

- настройки гиперпараметров;
- контроля процесса обучения;
- выбора подходящей конфигурации модели;
- контроля переобучения.

Тестовая выборка используется только для итоговой оценки качества.

Такой подход соответствует реальной задаче прогнозирования:

```text
прошлые данные → модель → прогноз будущих данных
```

## 15. Метрики качества прогнозирования

Для объективной оценки качества прогнозирования необходимо использовать количественные метрики.

В Demand Forecast предлагается использовать:

- MAE;
- RMSE;
- MAPE.

Применение нескольких метрик позволяет оценивать ошибку с различных точек зрения.

### 15.1 MAE

Mean Absolute Error представляет собой среднее абсолютное отклонение прогнозируемых значений от фактических.

Формула:

```text
MAE = (1 / n) × Σ|yᵢ - ŷᵢ|
```

где:

- `yᵢ` — фактическое значение;
- `ŷᵢ` — прогнозируемое значение;
- `n` — количество наблюдений.

Чем меньше значение MAE, тем меньше средняя абсолютная ошибка модели.

Преимуществом MAE является простая интерпретация результата в единицах прогнозируемой величины.

### 15.2 RMSE

Root Mean Squared Error определяется как квадратный корень из средней квадратичной ошибки.

Формула:

```text
RMSE = √[(1 / n) × Σ(yᵢ - ŷᵢ)²]
```

RMSE сильнее реагирует на крупные ошибки, поскольку отклонения предварительно возводятся в квадрат.

Это позволяет дополнительно учитывать случаи, когда модель допускает отдельные значительные ошибки прогнозирования.

### 15.3 MAPE

Mean Absolute Percentage Error представляет среднюю абсолютную процентную ошибку.

Формула:

```text
MAPE = (100% / n) × Σ |(yᵢ - ŷᵢ) / yᵢ|
```

Преимуществом MAPE является представление ошибки в относительном процентном виде.

Например, значение:

```text
MAPE = 8%
```

означает, что среднее абсолютное отклонение прогноза составляет около восьми процентов от фактического значения.

При этом MAPE имеет существенное ограничение.

Если:

```text
yᵢ = 0
```

вычисление классической формулы невозможно из-за деления на ноль.

Поэтому при реализации метрики необходимо предусмотреть обработку нулевых и близких к нулю фактических значений.

## 17. Выбор подхода для Demand Forecast

На основании проведённого анализа для Demand Forecast предлагается использовать два основных метода прогнозирования:

1. базовую модель;
2. нейросетевую модель.

Такой подход позволит не только получить прогноз, но и экспериментально определить, обеспечивает ли применение более сложного интеллектуального метода улучшение качества по сравнению с простым алгоритмом.

### 17.1 Базовая модель

В качестве базового метода предлагается использовать скользящее среднее.

Выбор обусловлен следующими причинами:

- простота реализации;
- низкие требования к вычислительным ресурсам;
- понятность алгоритма;
- отсутствие необходимости обучения;
- возможность быстро получить контрольный прогноз;
- удобство использования в качестве baseline.

Baseline необходим для объективной оценки интеллектуальной модели.

Если LSTM демонстрирует меньшую ошибку по MAE, RMSE и MAPE, чем скользящее среднее, можно сделать вывод о том, что применение нейросетевого метода обеспечивает улучшение прогнозирования на исследуемом наборе данных.

### 17.2 Интеллектуальная модель

В качестве основной интеллектуальной модели предлагается использовать LSTM.

Выбор обусловлен следующими причинами:

1. Исходные данные имеют последовательную временную структуру.
2. LSTM непосредственно предназначена для анализа последовательностей.
3. Модель способна учитывать долгосрочные зависимости.
4. Модель способна моделировать нелинейные закономерности.
5. LSTM широко применяется в задачах анализа временных рядов.
6. Модель может быть реализована с использованием распространённых ML-библиотек.
7. LSTM может быть изолирована внутри отдельного интеллектуального сервиса.
8. Сложность реализации соответствует масштабу курсового проекта.
9. Архитектура может быть расширена дополнительными входными признаками.
10. Полученные результаты можно количественно сравнивать с baseline-моделью.

## 18. Концептуальная схема интеллектуального компонента

Предполагаемый процесс обработки данных имеет следующий вид:

```text
Исторические данные
        ↓
Проверка входных данных
        ↓
Предварительная обработка
        ↓
Формирование временного ряда
        ↓
Масштабирование
        ↓
Формирование последовательностей
        ↓
┌───────────────────────┐
│                       │
↓                       ↓
Baseline              LSTM
↓                       ↓
Прогноз                Прогноз
│                       │
└───────────┬───────────┘
            ↓
       Оценка качества
            ↓
     MAE / RMSE / MAPE
            ↓
     Сохранение результата
```

Таким образом, один и тот же набор тестовых данных должен использоваться для получения прогнозов обеих моделей.

После этого результаты сравниваются с фактическими значениями.

## 19. Критерий сравнения моделей

Нейросетевая модель не должна автоматически считаться более эффективной только из-за большей сложности архитектуры.

Оценка должна выполняться экспериментально.

Пусть:

```text
Ebaseline
```

— ошибка базовой модели, а:

```text
ELSTM
```

— ошибка LSTM.

Улучшение качества по конкретной метрике можно оценивать как:

```text
Improvement = ((Ebaseline - ELSTM) / Ebaseline) × 100%
```

Если:

```text
ELSTM < Ebaseline
```

то LSTM показывает меньшую ошибку по выбранной метрике.

Если:

```text
ELSTM ≥ Ebaseline
```

то усложнение модели не приводит к улучшению результата по данной метрике.

Такой подход позволит объективно оценить целесообразность применения нейросетевой модели.

## 20. Ограничения выбранного подхода

Использование LSTM не гарантирует получение более точного прогноза по сравнению с простыми статистическими методами.

Качество модели зависит от:

- объёма доступных данных;
- качества исторических данных;
- длины временного ряда;
- наличия закономерностей;
- выраженности тренда;
- наличия сезонности;
- количества аномальных значений;
- длины входного окна;
- архитектуры сети;
- количества нейронов;
- количества слоёв;
- размера batch;
- скорости обучения;
- количества эпох;
- выбранной функции потерь;
- качества настройки гиперпараметров.

Также необходимо учитывать, что исторические закономерности не гарантируют сохранение аналогичного поведения спроса в будущем.

На спрос могут влиять факторы, отсутствующие в исходных данных:

- изменение цены;
- действия конкурентов;
- маркетинговые мероприятия;
- изменение экономической ситуации;
- дефицит товара;
- изменение потребительского поведения;
- внешние события.

Поэтому результат прогнозирования должен рассматриваться как аналитическая информация для поддержки принятия решений, а не как гарантированное значение будущего спроса.

## 22. Выводы

В результате анализа научно-технических подходов установлено, что задача прогнозирования потребительского спроса может решаться с использованием статистических методов, классических моделей временных рядов, алгоритмов машинного обучения и нейросетевых архитектур.

Простые методы, такие как скользящее среднее, отличаются высокой интерпретируемостью и низкой вычислительной сложностью, однако имеют ограниченные возможности при моделировании сложных зависимостей.

Классические модели ARIMA и SARIMA позволяют учитывать временные закономерности, тренды и сезонность, но требуют предварительного анализа ряда и настройки параметров.

Методы машинного обучения способны моделировать нелинейные зависимости и учитывать дополнительные факторы, однако требуют предварительного формирования признакового пространства.

Рекуррентные нейронные сети предназначены для обработки последовательных данных. Среди рассмотренных архитектур LSTM обладает механизмами долговременной памяти, позволяющими учитывать зависимости между удалёнными элементами временной последовательности.

По результатам анализа для Demand Forecast предлагается использовать скользящее среднее в качестве базового метода и LSTM в качестве основной интеллектуальной модели.

Качество прогнозирования должно оцениваться с использованием метрик MAE, RMSE и MAPE.

Итоговая оценка эффективности нейросетевого подхода должна выполняться на тестовой выборке путём сравнения ошибки LSTM с ошибкой базового метода.

Такой подход позволяет не предполагать преимущество интеллектуальной модели заранее, а экспериментально определить целесообразность её использования для прогнозирования потребительского спроса.
